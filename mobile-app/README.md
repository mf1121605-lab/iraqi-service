# Iraqi Service Mobile

This Expo app mirrors the Iraqi Service platform with native mobile screens for home, login, dashboard, requests, services, chat, profile, and request details.

## Run

1. cd mobile-app
2. npm install
3. cp .env.example .env
4. npm start

## Notes
- The app uses the same Supabase-backed data model as the web platform.
- Update EXPO_PUBLIC_SUPABASE_URL and EXPO_PUBLIC_SUPABASE_ANON_KEY in .env for real data access.
